# Contributing

By contributing, you agree that SkillBinder-owned contributions are provided under `AGPL-3.0-only`.

Keep application roots limited to `apps/frontend` and `apps/tauri`; keep shared Rust libraries limited to `libs/core`, `libs/db`, and `libs/platform`. Run `pnpm verify` before submitting changes. Never add imported skill content, credentials, private repository names, machine paths, installer signing material, or updater infrastructure to the repository.
