# Explore acceptance evidence

Part of [UI acceptance evidence](acceptance-evidence-ui.md). Explore's spec is [Explore and install](../../specs/explore-and-install.md); its acceptance checks are in [acceptance.md](../../specs/explore-and-install/acceptance.md).

Explore's catalog (#151) is covered by engine tests (`crates/engine/tests/catalog.rs`, `catalog/fetch.rs`, `catalog/snapshot.rs`) for a fetched catalog being cached with its ETag and served on the next launch with the source offline, a conditional request answered 304 keeping it, a refresh within the hour sending nothing and an older one sending `If-None-Match` with the `SkillBinder/<version>` user agent, a malformed entry dropped with the rest kept, a file over 8 MB or unreadable refused as Unavailable with the cache kept, a source without v1 or with another schema reported as Outdated with the cache kept, and a creator leaving the catalog taking their avatar; a client test for launch publishing the catalog's state; proto tests for URL normalization; and UI tests (`explore/query/tests.rs`) for Trending, creators ranked by installs, search by name, description, creator, and repository with its chips and counts, a picked creator narrowing the results and keeping its chip, "In library" only from the same source, and the installs label. `SkillCard` has its test-window tests. The packaged check against the live CDN (check 34) waits on the published catalog (#150).
