# Setup and application shell

## Setup and lifecycle

Four persisted steps cover prerequisites, source boundaries, optional synchronization, and final library creation. Backward navigation is allowed; forward skipping is refused. Git 2.39 or newer and writable storage are required. Library initialization stages an empty `skills/` directory and a repository before atomically publishing the directory, then reconciles the database with it. Completion is idempotent.

The executable owns the Tokio runtime and process lock. A second launch requests activation of the existing native window through an app-owned local marker. The Linux window uses the `skillbinder` application ID matching its desktop entry; Wayland compositors retain control over whether an activation request raises the window or requests attention. Shutdown cancels discovery, waits for a running source check, whose Git commands time out, and drains durable operations before flushing logs.

## Application shell

On macOS the window uses a transparent titlebar, so the shell fills the whole window and the traffic lights float over its top-left corner. Windows and Linux keep native decorations. The shell has a sidebar and a header.

The sidebar has a one-device-pixel right border, which is also the resize divider. In the light theme its background is slightly darker than the main surface, with a `#ebebeb` selection fill; in the dark theme it uses the reference design's `#161616` surface with a `#2f2f2f` selection fill. Its header row holds Back and Forward, right-aligned at the sidebar's trailing edge. Below it, 8 points down, sit the Discovery and Library rows; a Presets section with an Add preset button; a Workspaces section with an Add workspace button; an Agents section with no button; and Sync and Settings, pinned to the bottom. The Settings row grows to fill the sidebar width minus a trailing appearance toggle: a 32-point square ghost button, 1 point from the row, with a 16-point glyph in the unselected icon color. Rows are 32 points tall, 1 point apart, and inset 8 points from the sidebar edges. Each row has a 16-point Hugeicons glyph or agent logo, a 14-point medium label that truncates with an ellipsis, and optional trailing detail. Exactly one row shows the rounded selection fill: the current route's row, including a workspace, Universal, or an agent while its page is open. Sync has its own row. Discovery shows the number of found skills that are not in library, counting a skill with several versions once; scans show no loading state there. Library shows the number of managed skills. Sync shows a spinner while a Git operation runs and otherwise a blue dot when changes wait for Pull, Push, Sync, or a commit. Counts use tabular figures with thousands separators. Rows activate on click, Enter, or Space.

The Presets section lists every preset in its stored order, with the number of skills it holds while it holds any. A skill can be in several presets or in none, so there is no row for skills outside every preset; Library lists every skill. The Presets, Workspaces, and Agents sections scroll together between the top rows and Sync. One-device-pixel dividers in the sidebar border color edge that area: one 4 points below Library, shown while the sections are scrolled down, and one 4 points above Sync, shown while more of them lies below the visible area. The Presets title sits 4 points below the first, and the last section ends 4 points above the second. While the pointer is over the sidebar, a GPUI Kit scrollbar shows in the sidebar's trailing inset beside those sections at half opacity; it fades in over 300 milliseconds when the pointer enters and out over 500 milliseconds when it leaves. Reduced motion shows and hides it without fading. Clicking a section's title, or pressing Enter or Space on it, folds the section: over 180 milliseconds its rows slide shut and the chevron after the title turns from pointing down to pointing right, and unfolding reverses both. Reduced motion folds and unfolds without sliding or turning. An empty Presets or Workspaces section cannot fold: its title shows no chevron and ignores clicks. Folding a section leaves the open page and the active preset unchanged. Add preset and Add workspace show their label as a tooltip and unfold their section first. Folded sections are a machine-local preference that persists across restarts; preferences stored before it existed load with every section unfolded, and a section folded while presets were called folders stays folded. Clicking a preset activates it in place and opens no page; Library keeps listing every skill and its Active checkboxes follow the chosen preset. The active preset's row shows a check after its count and persists across restarts. The Library row is selected while Library or a skill's page is open. A preset's glyph is its icon, the Hugeicons layers glyph unless another is chosen, in its color: a palette color tuned separately for the light and dark themes, or a custom color. Add preset adds an inline name field at the end of the list; Enter creates the preset and Escape or leaving the field cancels it. Right-clicking a preset opens its context menu (see Context menus): Rename, which edits the name inline the same way and shows the new name at once while it saves; a refused rename restores the stored name and shows an error toast; Clone, which copies its name as "Copy of <name>", color, icon, and skills into a new editable preset directly after it; Color, a submenu with None, the eight palette colors, and Custom; Icon, a panel with a grid of 40 curated Hugeicons glyphs, eight per row; Move Up and Move Down; and Delete…, which opens the deletion preview. Default's menu holds only Clone, and its row cannot be dragged: the app never renames it, recolors it, re-icons it, moves it, or deletes it, and no other preset can move above it. A taken copy name gains a numeric suffix, such as "Copy of Review 2". Each menu row has a Hugeicons glyph in the unselected sidebar icon color. Color choices show the layers glyph in that color instead, with a check on the current one. Custom opens a third menu level beside the submenu that holds GPUI Kit's headless color picker, laid out as GPUI Kit lays out its own palette: a row of shades from dark to light for each of nine hues, then a hex field beside the hovered or current color. Choosing a shade, or entering a hex value and pressing Enter, saves that color and closes the menu. Custom leads with an empty ring until a custom color is picked, then with the layers glyph in that color and a check. A custom color drops any transparency and looks the same in both themes, while each palette color has a separate tone for each. The Icon row shows the preset's current glyph. Its grid draws every glyph in the preset's color and outlines the current one. The pointer or the arrow keys highlight a glyph, staying inside the grid, and a tooltip names the glyph under the pointer; clicking a glyph, or pressing Enter or Space, saves it and closes the menu. Delete… uses the theme's danger color for its glyph and label. Dragging a preset lifts it into a floating row with a shadow that follows the pointer, leaving its slot empty; the pointer shows a closed hand until release. The Default row never lifts, and a dragged preset stops at the first slot after it. As the floating row's centre crosses a slot, the other presets slide 180 milliseconds up or down to show the order a drop would save. Releasing the pointer anywhere saves that order, and the floating row settles into its slot. Move Up and Move Down slide the rows the same way; Move Up is unavailable for the first preset after Default. The new order is shown while it is saved, and a save that fails restores the stored order. Reduced motion moves rows without sliding. Right-clicking a row never focuses it: a row with a menu hands focus to the menu, and other rows leave it on the window.

The Workspaces section lists the workspaces the user added in their stored order, each with a code-folder glyph. While none is added the section shows only its title and Add workspace button. A workspace row's trailing detail is the number of skills the last scan found in its agent skill directories; a warning glyph replaces a workspace's count while its folder is missing. Clicking a workspace opens its page. Workspaces have the preset row affordances except color and icon: right-click opens Rename, which edits the name inline; Move Up and Move Down; and Remove…, in the danger color. Dragging a workspace reorders it exactly as presets reorder. Remove… asks for confirmation: "Removes the workspace from SkillBinder. Files in the folder are not touched."

Context menus are drawn by the app (`native_view/menu`) instead of GPUI Kit's `PopupMenu`, which fixes its row height, separators, and corner radius and has no opening animation. A menu opens with its top-left corner at the pointer and stays at least 8 points inside the window. It has 12-point rounded corners, 8 points of padding, a hairline edge drawn as a ring so a submenu covers it, and a soft shadow. Its surface is the popover color in the light theme and the muted color in the dark theme, a step above the sidebar. Rows reuse the sidebar row height and icon metrics: 32 points tall with a 16-point glyph. Labels are 13 points, the macOS menu size. A checked row shows a check at its trailing edge, and a row that opens a submenu or panel shows a chevron. Enabled rows show the pointing-hand cursor; disabled rows are dimmed, keep the arrow, and cannot be highlighted. Separators are hairlines inset to the row width. The metrics are in `skillbinder_theme::menu`. The menu fades in while sliding down onto its place with the theme's fast duration and enter curve; reduced motion skips the motion, and submenus, panels, and closing never animate. A submenu, or a panel of any content such as the icon grid, opens beside its row when the pointer moves onto the row, when the row is clicked, or with Right, Enter, or Space; from the keyboard a submenu highlights its first row and a panel takes focus. It overlaps the menu's edge by 4 points with its first row level with the row it opened from, and flips to the left when the window has no room on the right. When the pointer moves onto another row, including a disabled one, it stays open for 150 milliseconds, so a diagonal move toward it can cross the rows in between. Only one level of submenu is supported, but a submenu row can open a panel beside the submenu as a third level, such as the Custom color picker; it opens and closes as a submenu does, with the same 150-millisecond delay, and Right, Enter, or Space open it and move focus into it. The menu takes keyboard focus. Up and Down move the highlight, skipping separators and disabled rows and wrapping around. Left closes the submenu while the highlight is in it. Enter or Space chooses the highlighted row. Keys used in a panel, such as a hex field's, stay in it and never close the menu; Escape closes the panel and gives focus back to the menu, which also takes focus back when a panel closes while holding it, and Left does so while the menu has focus. Escape closes a submenu, or the menu when nothing is open beside it. Choosing a row closes the menu and then runs it, so an action that moves focus, such as Rename, keeps it; otherwise focus returns to where it was before the menu opened, or to the window when that element is gone, so shortcuts keep working. While a menu is open a backdrop covers the window: a press outside the menu closes it and does not reach what is underneath. The menu also closes when Tab moves focus away, when a shortcut runs while focus is not in a panel, or when the app goes to the background. The row a menu opened from keeps its hover fill while the menu is open. No keyboard shortcut opens a row's menu.

The Agents section lists the detected agents: the registry agents whose global skill directory exists on this device inside home. An agent whose directory lies outside home, or links out of it, is not detected, because the scan never reads it. The universal agents, those whose global skill directory is `~/.agents/skills`, share one Universal row with the Hugeicons layers glyph, first in the section whenever at least one of them is detected. The other detected agents follow alphabetically by display name ignoring case. The registry's own Universal agent reads a different directory, so its row adds that directory to its name, such as "Universal (~/.config/agents/skills)". The section, title included, is hidden while none is detected. Each row shows the agent's official logo and name, and its trailing detail is its number of found skills. Agents without bundled artwork show the Hugeicons square terminal glyph. Sidebar logos are monochrome and tint like other sidebar glyphs; Library avatars use full-color variants where bundled. Clicking Universal or an agent opens its page. Agent rows have no menu and cannot be dragged or renamed.
