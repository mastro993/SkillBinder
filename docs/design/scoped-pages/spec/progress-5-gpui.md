## Mapping

| Prototype element | Build it with | Exact? |
|---|---|---|
| Blocker, then wash | One last child of `NativeView::render`: `div().absolute().inset_0().occlude()`; after the reveal add `.bg(theme.background.opacity(0.7))` | Yes. | Pill container | A full-width row `h_flex().absolute().top(px(10.)).left_0().right_0().justify_center()` holding the pill `h_flex().h(px(34.)).pl(px(12.)).pr(px(14.)).gap(px(8.)).rounded_full().bg(theme::menu::surface(theme)).text_color(theme.popover_foreground).text_size(px(13.)).font_weight(FontWeight::MEDIUM).whitespace_nowrap()` | Yes. `menu::surface` = `#ffffff` / `#262626`, which is the prototype's popover. Centering on the window: the strip is a root-level overlay, not part of the main column. |
| Edge ring + shadow | `.shadow(vec![ring, lg1, lg2])`: ring = `BoxShadow::new(0, 0, theme.foreground.opacity(theme::menu::LINE_INK)).blur_radius(0).spread_radius(1)`; lg1 = `(0, 20)`, blur **12.5**, spread −5, black 0.1; lg2 = `(0, 8)`, blur **5**, spread −6, black 0.1 | Ring: AA-level only (G2). ## Gaps (CSS with no exact GPUI equivalent)

| # | CSS | GPUI fact (source) | Closest equivalent → expected delta |
|---|---|---|---|
| G1 | `box-shadow` blur = 2σ, an exact gaussian | `shadow_fragment` uses `blur_radius` as σ and integrates 4 samples along y (`shaders.metal` 497–545); GC `styled.rs` documents the halving | Halve the CSS radii. The 4-sample blur leaves the light halo up to 3 levels off on the flat page (measured with #104); the halo check allows 3/255. |
| G2 | The ring (spread 1) follows radius + 1 = 18 | `paint_drop_shadows` reuses the element's clamped radii (17) on the dilated bounds (`window.rs` ~4390, `style.rs` 705–711) | Ring end curves deviate by ≤ 0.4 px at 45°: AA-level |
| G3 | `line-height: 18.2px` | `line_height_in_pixels` rounds to whole px (`style.rs` 554–555) → 18 | Text sits up to 0.1 px off: glyph AA only |
| G4 | Chrome text rasterization | GPUI CoreText glyph atlas with subpixel x variants | Same font and metrics, so widths match within about 0.1 px, except weight 500, which GPUI draws with the Medium instance about 0.3% wider: the exact line lays it out at Chrome's width (Library G19); edge AA differs (yellow in pixdiff) |
| G5 | The wash covers the whole window | The traffic lights are AppKit `NSButton`s above the content view, and AppKit draws the window frame (rounded corners, edge hairline) above it too | Neither can be washed. The lights are masked `12,11,68,22`; pixdiff and `progress-checks.py` always leave out the frame: non-opaque pixels and those within 2 device px of them or the edge (part 4) |
| G6 | `animation: 0.9s linear infinite` | Kit `Spinner`: 0.8 s, `ease_in_out`, no speed setter (`spinner.rs`) | A custom `with_animation` (exact); stills mask the spinner anyway |
| G7 | `overflow: hidden` on a rounded box clips its children to the curve | `ContentMask` holds only `bounds` (`window.rs` ~2230); clipping is per-vertex `clip_distance` against a rect | The nested rect clip around a pill-shaped quad (above) is exact. The right end is a hard clip, ≤ 1 device px column. Where the bar's top edge meets the curve, 1–2 px antialias differently: an optional mask (part 4) in 04 and 05. |
| G8 | Small button 12 px / weight 500; outline fill = page bg; hover = `muted` | Kit `Button` small: `text_sm` 14 px through `button_text_size` (`sizing.rs` 328–332), no weight; `content_style` is `pub(crate)`; Default variant colors (`button.rs` 888–1130); a focus ring when focused (`button.rs` 866) | A child label, style overrides (the instance style is refined after the variant colors, `button.rs` 721) and `.focus_ring(false)`. Normal state exact. Hover: Kit hover `input` mixed 50% toward transparent (`#e5e5e5`@50% ≈ `#f2f2f2`) vs `#f5f5f5`, unless overridden with `.hover()`. |
| G9 | Bottom-center inverted toast, content width | Kit `Notification`: the stack is `theme.notification.width` 382 (global), default `Anchor::TopRight`, popover fill + 1 px border, `py_3p5 px_4`, 14 px text, icon absolute at (16,18), a hover close button, 5 s autohide, slide transition (`notification.rs` 403–470, 536–560, 1009–1070) | A custom toast element (exact). Kit `Notification` styled through `Styled` still keeps a fixed width and its own layout, so it cannot reach parity. |
| G10 | `cursor: progress` on the blocker | `CursorStyle` has no progress/wait cursor (`platform.rs` ~2567) | `Arrow` (not visible in screenshots) |
| G11 | Pill enter (0.18 s, −6 px, fade), wash fade 0.2 s, toast rise 0.2 s, bar width 0.2 s | `with_animation` can animate opacity, offset and width; there are no CSS transitions | Same timings by hand; not part of still parity |
| G12 | Fractional x (`translateX(-50%)`: pill x 510.05) | Layout floats, but `paint_quad` snaps each quad to whole device pixels (`window.rs` 4506); text origins snap to subpixel variants | Up to 1 device px at the left and right edges: snap, within the state's budget, and the halo check's ignore box is 1 device px wider there (part 4) |
| G13 | SVG icons at fractional positions (done glyph, check-circle, the review's alert-circle) | `paint_svg` rounds the sprite origin half toward zero and its size up (`window.rs` 4813, 4847–4848) | Up to 1 device px: snap, within the budget. A stroke about 2 device px wide, such as the alert-circle's "!" stem, can land at another sub-pixel phase: one column gets more ink than any reference pixel. pixdiff counts those 4–6 px per glyph as `icon` residue (Library G18; README) |

Nothing in this area needs blur or `backdrop-filter`. The wash replaces the user-seen blur.
