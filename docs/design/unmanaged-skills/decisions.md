# Skills SkillBinder does not manage: design decisions

The user settled these on 2026-11-26. Behavior comes from [the spec](../../specs/unmanaged-skills-on-pages.md) and [ADR 0036](../../adr/0036-pages-list-what-skillbinder-does-not-manage.md). They add to [scoped-pages' decisions](../scoped-pages/decisions.md) and [ignore-skills' decisions](../ignore-skills/decisions.md), whose ids stay valid. Ids are stable; cite them from issues.

- **U1** Layout is variant A "Sections". The page keeps its search field and its card of skills on here, unchanged. Under that card come up to three sections, in this order: "Not in library", "In library, off here", and "Ignored". A section with no rows is absent.
- **U2** A section's head is one line: its title in semibold, its count in muted figures, and a muted hint. "Not in library" reads "Agents load these; SkillBinder does not manage them", and "In library, off here" reads "Your library has them, but they are not on here". The rows follow in a bordered card like the list above them.
- **U3** A "Not in library" row shows the slug with its validation glyph, the description ("No description" when empty), and a muted mono line. On a workspace's page that line names the directories holding the skill, such as `.claude/skills`. On every page it then adds "Also found in <places>" when the skill was found elsewhere. The rows are not links, since a found skill has no page.
- **U4** A "Not in library" row ends with a small ghost "Ignore" and a small outline "Import…", both shown while the row is hovered or holds keyboard focus, like Delete on Library rows. Ignore's tooltip is "Ignore everywhere: never offered for import", and the accessible names are "Ignore <slug>" and "Import <slug>".
- **U5** The "Not in library" head ends with a small ghost "Ignore all" and a small outline "Import…". Ignore all ignores every skill the section lists, including rows the search hides. Ignoring follows I4: it is saved at once, there is no toast, and the Ignored section is the undo.
- **U6** Import… opens the Import skills dialog with only this place's not-in-library skills: from a row, only that skill. Every rule of the dialog holds inside it: its versions, its 500 cap, and its ticks. Each listed skill still shows every location it was found in, and importing turns it on wherever it was found.
- **U7** An "In library, off here" row is a Library row of that skill, so clicking it opens the skill's page. It is dimmed, shows "Different copy" as an outline tag when the copy's content differs from the library, and on a workspace's page names the directories where the copy sits. It ends with a small outline "Turn on":
  - On an agent's or Universal's page, Turn on turns the skill on for that page's global skill directory in the active preset. Its tooltip is "Turn on for <agent> in <preset>".
  - On a workspace's page, "Turn on ▾" opens a menu headed "Turn on for". It offers "All agents", then each of the workspace's directories, the ones holding a copy marked "copy here" and the ones already on disabled. With no directories, it is disabled with the tooltip "No agents here yet".
  - Turn on makes the same change as Add skill. A different copy then asks through the Skill copies dialog (Replace or Skip), and the row moves to the list above once the copy is on.
- **U8** The Ignored section's head is a disclosure: a chevron, "Ignored", the count, and the muted hint "Not offered for import anywhere". It starts collapsed on every page visit. Its rows follow I6: dimmed, with the page's directory line and a small outline "Stop ignoring". Stop ignoring moves the row back to "Not in library" and flashes it.
- **U9** The search narrows every section by slug or description, ignoring case. While a query matches an ignored skill, the Ignored section shows expanded with only its matching rows (I9). "No skills match '<query>'" replaces the page only when no section matches.
- **U10** A page with nothing on keeps its empty state above the sections, as one line in the card: "No skills on in <place>", plus " · No agents here yet" for a workspace with no directories. With nothing found either, it keeps today's full empty state with Add skill.
- **U11** Sidebar counts, Scan for skills' count, and the Add skill picker do not change.
- **U12** Copy: "Not in library", "In library, off here", "Ignored", "Ignore", "Ignore all", "Import…", "Turn on", "Stop ignoring", "Different copy". Never "unmanaged" or "stray" in the window; those are spec words.
