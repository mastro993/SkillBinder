On 2026-10-17, a macOS ARM64 MCP session with an isolated data directory and a fixture home under `/tmp` verified library folder reordering. After onboarding, three folders were created inline: Alpha, Beta wide folder name, and Gamma. Native pointer drags were captured mid-gesture. While Alpha was dragged rightward over Gamma, a floating copy with a shadow followed the pointer and a bar marked Gamma's trailing edge. Releasing it there saved Beta wide folder name, Gamma, Alpha, and All skills stayed chosen. A drag released below the header left the order unchanged. Dragging Alpha leftward onto the wider Beta tab moved it into Beta's slot, and `library_folders` held Alpha, Beta wide folder name, and Gamma at positions 0 through 2. After it, dragging Alpha onto Gamma left the window in place and saved Beta wide folder name, Gamma, Alpha, while a drag across the header's empty area still moved the window.
