# Native interaction checklist

Use disposable source directories, library data, and a local bare remote.

1. Complete all four setup steps and the first import's review with skills in a fixture home's global skill directories, one of them in two versions; confirm the review states the replacement, then that Default holds each skill for the agents that had it. Quit and reopen between steps to verify resumption.
2. Select a project directory through the native picker, register it, rename, reorder, and remove it, then verify direct agent skill discovery. Pick the home folder and confirm that only the projects in it are added, or that the pick is refused when it holds none.
3. Scan, select candidates, acknowledge invalid metadata when applicable, review and apply an import. Navigate during work; retain the result until dismissed. Confirm original source bytes remain unchanged.
4. Search Library, inspect a file, create, recolor, reorder, rename, clone, and delete a preset through its revision-checked preview, and confirm that the Default preset's only menu action is Clone, that it cannot be dragged or recolored, stays first, and keeps its name and glyph. Activate and deactivate skills in the active preset from a row's popover, a row's menu, and a skill page; confirm the All, Active, Inactive, and Updates filters narrow the list with the folder tab and search, their counts follow, Clear filters resets them, the choice survives a visit to Discovery and not a relaunch, and a workspace's page has no filter row; confirm clicking a preset activates it without opening a page and that the active check follows it, that a switch slower than 300 ms shows the progress strip with a rising percentage while clicks, Escape, ⌘B, ⌘[ and ⌘] do nothing, that a switch between presets holding the same skills shows only the toast when no copy waits for the user, and that each switch ends with `Switched to <preset>`, and confirm a new empty preset shows the "No skills active in <name>" notice in Library. Rename a preset to a duplicate and confirm the row reverts to the stored name with an error toast. Create and clone presets and confirm their rows appear before the save completes; a refused creation removes the row with an error toast. Confirm that importing a different skill with a slug the library holds is refused.
5. Start the native test build with `--home` set to a disposable fixture home holding `.claude/skills` and `.agents/skills`. Open an inactive skill's dashed `+`, confirm the popover names the active preset, turn All agents on, and confirm its copy appears in both directories, the row's stack shows Universal and Claude Code, and the agent pages tag it `Managed copy`; turn All agents off and confirm both copies stay, turn Claude Code's pill off and confirm only `~/.claude/skills/<slug>` goes, then turn the last pill off and confirm the copy disappears without a dialog, other skill folders stay, and the row dims. Turn a workspace's pill on and confirm the copy appears there and the row gains its chip; a workspace using no agent reads `No agents yet`, and a missing one's line does nothing. Confirm the popover stays open across changes, closes on Escape and a press outside, and that Enter on a row still opens the skill page. With Tab focus the trigger and press Enter: no control is outlined until Tab, Tab and Shift-Tab cycle the switch and pills with the outline, Space and Enter toggle them, and Escape returns focus to the trigger. Close it with a second click on `+`, press cmd-B twice, and confirm that row's `+` stays hidden. Reach Library from another page, open a popover, Tab to a pill, press cmd-[, and confirm cmd-] still returns to Library. Switch to a preset holding other skills and confirm the files swap, then open the delete confirmation for the active preset, confirm it states what Default adds and removes, delete it, confirm the strip takes over from the confirmation and ends with `Deleted <preset> · Switched to Default`, and confirm the files match Default. Edit a managed copy and switch away: the strip ends with `Done · 1 needs attention`, Review opens the review list with Remove and Keep, and Close leaves no dialog open. Put a different copy of a library skill's slug in the fixture, activate the skill, and confirm Skill copies opens with Replace and Skip while the copy stays untouched until answered. Edit a managed copy, deactivate its skill, and confirm Remove and Keep. Make a fixture directory read-only, activate a skill, and confirm the warning glyph, its tooltip, and the skill page's Review note, then make it writable and confirm Retry applies the copy. Quit during a long switch, with ⌘Q and by killing the process, and confirm that every copy in place is complete, that no `.skillbinder-` staging directory remains after relaunch, and that the next launch finishes the switch.
6. With the same fixture home, add a project folder holding a library skill's identical copy in `.claude/skills` and a different one in `.agents/skills`. Confirm the add writes nothing, Skill copies asks about the different copy, and the workspace's page shows the skill active with its avatars. Toggle another skill there and confirm its copy appears in the project's directories only; hold it for one directory from the agents button, add a detected agent's directory and confirm it is created; activate a skill held for your agents and confirm `Also in your agents`. Add an empty project, check Active, and confirm Choose agents lists each directory once and Activate writes the copy. Remove the workspace and confirm the copies stay.
7. Connect a disposable remote. Confirm Refresh does not commit, Push explicitly commits only `skills/`, preset and folder changes and managed copies never show as changes, Pull is fast-forward only, and Disconnect retains local files.
8. Type, select, copy/paste, and compose through an IME. Check Tab/Shift+Tab, dialog focus, Escape dismissal, pending dismissal locks, directory-picker cancellation, appearance, and reduced motion.
9. Resize, hide, and show the sidebar with the pointer, header toggle, and Cmd+B or Ctrl+B. Resize the window, restart, confirm the sidebar width and hidden state persist, launch a second instance, and close the final window. Verify native activation, persisted data, and process exit.
