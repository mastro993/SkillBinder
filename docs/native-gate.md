# Verify the native application

The workspace implements the shipped product journeys with pinned GPUI Kit. Functional coverage is documented in [native features](features/native.md). Visual fidelity and polish are deferred, except for surfaces with an approved prototype in `docs/design/`: they follow its design (layout, hierarchy, copy, icons, states, and behavior) using GPUI Kit components first, and small visual differences from Kit are fine. The [design reference](design/scoped-pages/README.md) lists the prototypes and the settled decisions.
